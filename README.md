# 食光记

一个基于 [vitepress-blogs-theme](https://github.com/chunge16/vitepress-blogs-theme) 构建的美食博客。

## 关于

记录家常菜谱、烘焙甜点与探店体验，把每一餐都变成值得分享的故事。

## 技术栈

- [VitePress](https://vitepress.dev/) - 静态站点生成器
- [vitepress-blogs-theme](https://github.com/chunge16/vitepress-blogs-theme) - 博客主题
- [Tailwind CSS](https://tailwindcss.com/) - 样式框架

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run docs:dev

# 构建静态站点
npm run docs:build
```

## 博客内容

- **家常菜**：红烧肉、清蒸鱼、热汤面
- **烘焙**：戚风蛋糕
- **饮品**：手冲咖啡
- **探店**：藏在巷子里的三十年老面馆

## 部署

构建产物位于 `docs/.vitepress/dist/`，可部署至任意静态托管平台。
